# WebFluxTodo

WebFluxTodo with test case reail time application

## Common Service
```shell
     ./gradlew :CommonService:build -x test
```

## WebFluxTodo build
```shell
     ./gradlew clean build -x test 
```
## WebFluxTodo with test case
```shell
     ./gradlew :WebFluxTodo:bootRun -x test
```
## UserManagement
```shell
     ./gradlew :UserManagement:bootRun
```


### UserManagement
```shell
     ./gradlew :UserManagement:bootRun
```

## UserManagement run stacktrace
```shell
    ./gradlew :UserManagement:bootRun --stacktrace
```


## UserManagement run with debug
```shell
    ./gradlew :UserManagement:bootRun --stacktrace --debug
    ./gradlew :UserManagement:bootRun --stacktrace --info

    ./gradlew :UserManagement:bootRun --stacktrace --debug

```
